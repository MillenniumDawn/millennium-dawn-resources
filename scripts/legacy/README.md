# Legacy scripts

Archived from the main Millennium-Dawn repo's `tools/old/` directory. These are
unmaintained one-off scripts that predate the current `tools/` layout
(`linting/`, `validation/`, `standardization/`, `generators/`). Nothing wired
into the mod's pipeline used them — they're kept here for reference only.

Most are superseded by current tools (OOB/ID checks, leader and tooltip
generators). Several have spaces in their filenames and can't be imported as
modules, so they only ever ran as standalone scripts. No guarantee any still
work against the current data format.
